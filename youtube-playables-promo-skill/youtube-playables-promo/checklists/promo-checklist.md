# Promo kit checklist

## Setup
- [ ] Game hooks (`?debug`, `?dpr`, `?capture`, one-step helpers) are gated off inside Playables; build + audit still pass.
- [ ] Dev server watcher ignores the output folder.
- [ ] `codex` smoke test produced an image.

## Raw AI art (review each at full size)
- [ ] Logo spelled exactly right, no extra words.
- [ ] No stray text/letters/numbers/watermarks in any art.
- [ ] Hero colours and design match the game; only real content shown.
- [ ] Family friendly: no people, gore, weapons aimed at people.
- [ ] Safe areas respected (hero survives 16:9 / 9:16 / 1:1 / 3:1 crops).

## Built kit
- [ ] `manifest.json` sizes match `references/requirements.md`.
- [ ] Icons square, opaque, readable at 48 px; favicon present.
- [ ] Banners: 16:9 1920x1080 (+480x270, 240x135), 9:16 1080x1920 (+270x480, 135x240).
- [ ] Logo never overlaps the hero; tiny sizes have no logo.
- [ ] >= 3 store screenshots per orientation, exact 1920x1080 / 1080x1920, real captures, uncluttered.
- [ ] Device screenshots for phone tall/wide, tablet portrait/landscape, desktop.
- [ ] Preview MP4 1920x1080 plays smoothly, opens on action, loops sensibly; portrait version too.
- [ ] Contact sheet reviewed at small size: every tile readable.

## Submission
- [ ] Official portal requirements re-checked (date in requirements.md).
- [ ] Asset rights confirmed (model terms), prompt logs kept.
