# Thumbnail Style

## Goal

The thumbnail should explain the game's main fantasy in one glance.

A useful formula is:

**one hero subject + one obvious interaction + one consequence**

Examples:

- ball smashing through stacked obstacles
- car visibly crushing another car
- saw blade ricocheting through frozen balloons
- character choosing between two transformations

## Composition

- Make the primary subject extremely large.
- Use 1–3 focal objects, not a full gameplay scene.
- Crop aggressively.
- Use strong foreground/background separation.
- Prefer diagonal motion and visible cause/effect.
- Leave empty space around critical silhouettes.

## Color

- bright background or clean gradient
- saturated hero object
- contrasting action effect
- avoid many similarly saturated competing objects

## Readability test

Downscale the thumbnail until it is roughly the size it would appear in a discovery shelf.

If the mechanic no longer reads, simplify it.

## AI generation

AI image models are well suited for:

- initial thumbnail variations
- composition exploration
- clean stylized renders
- background replacement
- impact/debris enhancement

Use the actual game's visual language as reference. Do not create a thumbnail that implies gameplay or content the game does not contain.

## Avoid

- tiny characters
- walls of UI
- title/logo dominating the image
- detailed scenery competing with the subject
- five unrelated mechanics in one image
- realistic rendering if the game itself is simple/cartoonish
