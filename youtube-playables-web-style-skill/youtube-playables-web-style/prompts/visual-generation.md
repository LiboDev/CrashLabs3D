# Visual Generation Prompt Patterns

These are structures, not fixed prompts. Replace bracketed fields.

## 2D object

> [OBJECT], clean hybrid-casual 2D game asset, large simple silhouette, rounded chunky forms, flat saturated colors, one soft shadow tone and one highlight tone, [VIEW ANGLE], isolated composition, minimal internal detail, readable at small size, consistent light from upper left, no text, no logo, no background clutter.

## 2D environment

> [SCENE], stylized casual web-game environment, simple layered shapes, clean vector-like rendering, restrained background saturation, large readable forms, sparse props, strong separation between gameplay space and decoration, [PALETTE], no text, no characters unless specified.

## 3D concept render

> [OBJECT/SCENE], toy-like low-poly 3D game art, chunky bevelled geometry, simple matte/plastic materials, broad highlights, bright controlled palette, soft global illumination, one clear directional key light, minimal texture detail, mobile/web game aesthetic, gameplay-readable silhouette, [CAMERA ANGLE], uncluttered background.

## Thumbnail

> Promotional thumbnail for a casual web game showing [HERO SUBJECT] [CORE ACTION] causing [VISIBLE CONSEQUENCE]. One dominant subject, exaggerated motion, strong diagonal composition, bright simple background, saturated toy-like game rendering, clear cause and effect, readable at very small size, minimal secondary objects, no title text, no logo, accurately represents gameplay.

## UI icon

> [ICON SUBJECT], chunky casual game UI icon, centered, bold silhouette, simplified geometry, saturated color, soft highlight, subtle depth, no text, transparent background, readable at 32px.

## Upgrade card art

> Icon illustration for the upgrade “[UPGRADE]”: [EFFECT]. One dominant object, exaggerated visual identity, clean hybrid-casual game style, simple silhouette, limited colors, isolated composition, no text, transparent background.

## Negative constraints

Append when appropriate:

> Avoid photorealism, tiny details, complex scenery, illegible silhouettes, thin lines, muted low-contrast colors, text artifacts, logos, watermarks, inconsistent lighting, excessive texture noise.
