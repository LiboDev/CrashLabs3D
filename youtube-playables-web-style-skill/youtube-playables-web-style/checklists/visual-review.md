# Visual Review Checklist

## Readability

- [ ] Can the main gameplay object be identified immediately?
- [ ] Is the current goal obvious without reading instructions?
- [ ] Are hazards visually distinct from rewards?
- [ ] Does the scene still read when viewed small?
- [ ] Is the background less visually dominant than gameplay?

## Consistency

- [ ] Do all assets share the same shape language?
- [ ] Is lighting direction consistent?
- [ ] Are outlines/shadows consistent?
- [ ] Are material categories visually distinct?
- [ ] Do generated assets look like they belong to one game?

## Feedback

- [ ] Do collisions have visible feedback?
- [ ] Do damage and destruction states read clearly?
- [ ] Are chain reactions easy to follow?
- [ ] Are major events visually stronger than routine events?

## UI

- [ ] Is text readable on mobile-sized displays?
- [ ] Are buttons large enough for touch?
- [ ] Are health/progress bars visually tied to their targets?
- [ ] Does HUD avoid obscuring gameplay?

## Web performance

- [ ] Are repeated meshes instanced/reused?
- [ ] Are textures appropriately sized/compressed?
- [ ] Are particle counts bounded?
- [ ] Is transparent overdraw controlled?
- [ ] Does the game remain smooth during the busiest visual sequence?

## Thumbnail

- [ ] Is there one dominant subject?
- [ ] Does the image show the core mechanic rather than generic art?
- [ ] Does it remain understandable at discovery size?
- [ ] Does it accurately represent the game?
